# 任务页首屏设计

## 目标

将移动端任务列表改成参考图中的“远程”首屏：用户打开页面后可以先看到 Mac 连接状态、项目列表和聊天列表，并在底部快速搜索或开始新聊天。

## 页面结构

1. 顶部导航
   - 左侧圆形菜单按钮，打开任务、待办和 Mac 页面入口。
   - 中间显示“远程”和当前连接的 Mac 名称。
   - 右侧圆形更多按钮，复用同一个导航操作面板。
2. 项目
   - 使用 Remote Host 返回的 `WorkspaceSummary[]`。
   - 每行显示文件夹图标、项目名称和新建聊天操作。
   - 点击某个项目右侧的新建聊天时，将该项目工作区带入现有的新任务流程，并自动预选；底部通用“聊天”按钮仍允许用户自行选择工作区。
3. 聊天
   - 使用当前已经过滤过的可见会话列表。
   - 保留会话标题、更新时间排序和点击进入详情页的行为。
   - 搜索有输入时展示现有的服务端搜索结果。
4. 底部操作栏
   - 固定显示搜索聊天输入框和蓝色“聊天”按钮。
   - 输入框仅改变列表筛选，不改变远程协议。

## 行为约束

- 会话详情页、草稿保存、审批、推送通知和断线重连逻辑保持不变。
- 首屏不再显示旧的底部三栏导航；菜单面板仍提供待办和 Mac 入口。
- 项目和聊天为空时，显示明确的空状态并保留新建任务入口。
- 主机名称使用当前访问域名的首段作为展示名；本地开发地址回退为“远程 Mac”。

## 验收标准

- 手机宽度下首屏视觉层级接近参考图：顶部居中标题、项目/聊天分组和底部双操作栏。
- 所有项目行能显示真实工作区名称，所有聊天行能打开现有会话详情。
- 搜索、新建任务、待办、Mac 页面和断线状态仍可访问。
- 移动端类型检查、单元测试和生产构建通过。

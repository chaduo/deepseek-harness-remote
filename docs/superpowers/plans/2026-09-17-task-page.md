# Task Page Reference Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework the mobile task-list first screen to match the supplied “远程 / 项目 / 聊天” reference while preserving the existing remote session behavior.

**Architecture:** Keep `App.tsx` as the stateful composition layer and make the task-home branch a presentation layer over the existing workspace/session props. Add a small pure page-model module for deterministic host naming and chat ordering, then use CSS media-safe fixed bottom actions and an in-page navigation sheet for the new mobile chrome.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, existing CSS token system.

## Global Constraints

- Preserve the existing `workspace.list`, `session.list`, history, draft, approval, push and reconnect flows.
- Do not add a UI dependency; use the existing inline SVG icon system.
- Keep light and system dark themes working through existing CSS variables.
- The task home must leave enough bottom padding for the fixed search/chat toolbar.
